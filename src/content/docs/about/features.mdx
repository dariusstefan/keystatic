title: Features
description: A detailed list of OpenSIPS features and capabilities.
---

## Core SIP Stack

- Robust and performant SIP (RFC 3261) Registrar, Location, Proxy and Redirect server
- Stateless and transactional stateful SIP proxy processing
- Support for UDP, TCP, TLS and SCTP transport layers
- IPv4 and IPv6
- Support for SRV and NAPTR DNS, with SRV DNS failover
- Multi-homed and multi-domain support
- IP Blacklists

## Architecture

- Small footprint — the binary is compact; functionality is added via modules
- Plug-and-play module interface — extend without touching the core, keeping core stability high
- Modular design with over 100 modules in the official repository

## Scripting & Routing

- Flexible and powerful scripting language for routing logic
- Script variables, pseudo-variables (access to SIP message fields), and AVPs (per-transaction persistent values)
- Transformations on script variables
- Asynchronous scripting support

## Authentication & Security

- Digest and IP authentication
- Authentication, Authorization and Accounting (AAA) via database (MySQL, PostgreSQL, flat files), RADIUS and DIAMETER
- CPL — Call Processing Language (RFC 3880)
- STIR/SHAKEN support

## Presence & IM

- Presence Agent with extensive integration features
- XCAP support for Presence Agent
- SIP IM server (chat and end-to-end IM)
- SIP to XMPP gateway for presence and IM (bidirectional)
- Resource List Server (RLS)

## Media & Gateways

- NAT traversal support for SIP and RTP traffic
- SIP to SMS gateway (AT based)
- SIP to XMPP gateway (transparent server-to-server translation)
- Straightforward interconnection with PSTN gateways
- MSRP relay

## Routing & Load Management

- Load balancing with failover
- Least cost routing (LCR)
- Dynamic routing and dialplan features
- SIP dispatcher

## Dialog & Call Control

- Dialog support — call monitoring, call termination from proxy side, call profiling
- SIP back-to-back User Agent (B2BUA)
- SIP front-end for gateways / Asterisk / FreeSWITCH

## Databases & Caching

- Multiple database backends: MySQL, PostgreSQL, Oracle, Berkeley DB, flat files, and any database with a UnixODBC driver
- Key-value caching interface (Redis, Memcached, etc.)

## Management & Monitoring

- Management Interface (MI) via HTTP, datagram, XMLRPC or FIFO
- Statistics Interface for live metrics
- Event Interface for asynchronous notifications
- SNMP interface

## Integration

- PERL programming interface — embed Perl extensions
- Java SIP Servlet application interface
- ENUM support
- Logging with custom messages including any header or pseudo-variable

## Scalability

- Runs on embedded systems with limited resources — hundreds of call setups per second
- As a stateless load-balancer, over 5,000 call setups per second
- On systems with 4 GB of RAM, serves a population of over 300,000 online subscribers
- Horizontal scaling by adding more OpenSIPS nodes
- Suitable for geographically distributed VoIP platforms
- Straightforward failover and redundancy
