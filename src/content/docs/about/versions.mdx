## Current Releases

* **3.6.x** is the current Long Term Support (LTS) stable release, maintained until May 2028.
* **4.0.x** is in beta. It is not yet recommended for production use.
* **4.1.x** is under active development on the `master` git branch.

## Release Policy

OpenSIPS follows a roughly annual major release cycle. LTS releases receive security fixes and critical bug fixes for an extended period (typically 3 years). Standard releases are maintained until the next major version ships.
