**OpenSIPS** (**Open** **SIP** **S**erver) is a mature *open source* SIP server. More than a proxy or router, it includes application-level functionality that makes it the core component of any SIP-based VoIP solution. With a flexible routing engine and a modular design, OpenSIPS unifies voice, video, IM and presence services — at a scale that ranges from small deployments to enterprise and carrier-grade platforms.

**Prerequisites**

OpenSIPS runs on most \*nix systems. Deploying it requires basic Linux familiarity, some [SIP (RFC 3261)](https://www.ietf.org/rfc/rfc3261.txt) knowledge for non-trivial scenarios, and comfort with a C-like scripting language for developing routing logic.
